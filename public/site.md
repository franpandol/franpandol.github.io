## Projects

Production case studies and open-source backends: problem, solution, impact, and stack.

### AWS Infra Report

**Problem.** Cloud accounts accumulate idle resources, open security groups, and opaque networking — waste and risk that are hard to see without hours of console clicking.

**Solution.** Built a read-only Python auditor with boto3 that maps VPC/compute topology into an interactive Mermaid diagram, ranks findings (CRITICAL→LOW) with copy-pasteable aws CLI fixes, and estimates monthly cost waste.

**Impact.** Shows production AWS fluency — networking, ECS, ELB, RDS, CloudWatch — packaged as a single-file, shareable HTML report teams can run without granting write access.

**Stack:** Python, boto3, AWS, Mermaid

- GitHub: https://github.com/franpandol/aws-infra-report

### MURAL Python Client

**Problem.** Integrating with the MURAL Public API from Python meant hand-rolling OAuth, pagination, and untyped JSON for dozens of endpoints.

**Solution.** Shipped a typed SDK covering the OpenAPI surface: Pydantic v2 models, OAuth2 with auto-refresh, transparent cursor pagination, a Typer CLI, and a full exception hierarchy.

**Impact.** Demonstrates library-grade API design — client-side validation, 98+ mocked tests at ~99% coverage — the same patterns used for reliable third-party integrations in production backends.

**Stack:** Python, Pydantic, httpx, OAuth2, Typer

- GitHub: https://github.com/franpandol/unofficial-mural-python-client

### CV Generator

**Problem.** Professionals need portable, version-controlled CVs that render consistently across formats — without locking content into proprietary tools.

**Solution.** Built an open-source CLI and in-browser app: Pydantic validates the JSON source, Jinja2 renders it, WeasyPrint exports PDF, and a Pyodide-powered web app runs the whole pipeline client-side with no server.

**Impact.** Demonstrates end-to-end Python tooling — schema validation, templating, PDF generation — plus WebAssembly delivery for zero-dependency distribution.

**Stack:** Python, Pydantic, Jinja2, WeasyPrint, Pyodide

- GitHub: https://github.com/franpandol/lebenslauf-generator
